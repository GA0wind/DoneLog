## 本次修复

1. 使用 `UniRadioGroupChangeEvent`、`UniPickerChangeEvent`、`UniSwitchChangeEvent`、Swiper 事件的实际类型，避免将原生事件强转为 `UTSJSONObject` 的 `ClassCastException`。
2. 用带点击事件的 `view` 替代 Android VDOM 不支持的 `label`，支持点击选项文字切换。
3. 将本项目中的值比较改用 `==` / `!=`。UTS 的 `===` / `!==` 是引用比较，曾导致默认标签重复生成、字符串及数值判断不可靠。
4. 将滚动容器显式绑定为 `:scroll-y="true"`，修复长页面无法滚动以及底部入口无法访问。
5. 对日历初始化月份、空历史记录和番茄钟关联事件增加数组边界保护，修复空数组越界和日历白屏。
6. 完成总数直接统计完成记录，避免多标签重复累计。
7. 分类占比对多标签记录按分均分金额，并用原生支持的比例条替代未显示的 `conic-gradient`。标签预算继续统计完整关联金额。
8. 组件快照解析按 JSON 根类型区分旧数组与新对象，修改事件时保留真实当天收支。
   按标准插件入口导入，使 Provider、Bridge Activity、Manifest 与布局作为独立模块导出；并补齐两个 Android 类的父类构造调用，确保原生编译通过。
9. 360 × 640 dp 小屏下记账弹窗保存按钮被裁切，主表单改用限高的滚动容器；修复后进行小屏回测。
